# 课件用户功能（admin-hub + 智能课件 A701）

- 日期：2026-05-31
- 范围：admin-hub 加「课件用户」管理 + 智能课件(A701)登录改白名单准入
- 状态：代码完成 + 本机端到端验证通过；**P5 生产部署未做（红灯，待指令）**

## 目标
授权管理员在后台「服务管理 > 课件用户」增删改课件用户；只有在册且 active 的手机号能登录智能课件；
管理员只看/只能操作自己加的用户（超管看全部）。

## 关键事实
- **在用的智能课件目录是 A701**（v1.0.2 main，admin-hub env 指向它）。A700 是旧目录，勿改。
- A701 端口 4701；admin-hub 本机 3001 / 生产 3004，basePath /b100。

## 架构决策（已落地）
1. 白名单表 `courseware_users` 在 admin-hub 主库(career-report.db)，admin-hub 全拥有 CRUD（零跨库写）
2. 字段：id / phone(UNIQUE) / name / added_by_admin_id / note / note2 / status(active|disabled) / created_at / updated_at
3. 「最后登录时间/使用次数」不存本表，列表查询跨 ATTACH 只读 teaching 库算（last_login_at←teaching.users；usage_count←COUNT teaching.reports）
4. A701 登录调 admin-hub `POST /api/teaching/gate`（shared secret，fail-closed）；不在 /api/admin 下，proxy 不拦，route 自校验 secret
5. 权限：菜单 key `courseware-users`；accessFilter by added_by_admin_id（超管全看），同 service-tracking
6. 干净切换：不迁移现有登录过的用户（2026-05-31 用户确认）
