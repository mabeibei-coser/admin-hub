# 智能体包装响应式部署

## 目标
- 将已验证的响应式修复发布到 `h100.jsai100.com`，使同一包装页在手机与电脑端获得真实视口宽度。

## Phase 与验收
1. Pre-flight：确认本次改动可隔离、无密钥、服务器目录/PM2/basePath/远端 Git 状态正常。
2. 本地发布：测试与 build 通过；仅提交组件、版本号和本计划；生成 patch tag 并推送。
3. 服务器更新：`git pull --ff-only`、`npm ci`、build、PM2 restart 均成功，服务器 Git 与 tag 一致。
4. 线上回归：目标 URL 最终 200；390px 内页宽 390，1440px 内页宽 1440；无缩放且遮罩保留。

## 已知风险
- 根域 `?no=` 由 Nginx 映射到 B100；本次不改路由，只验证现有映射。
- 服务器若有未提交人工改动，先留可恢复 stash；敏感或无法判断则停止。
- 构建或 PM2 失败时保留旧进程/旧提交证据，不修改业务数据。

## 决策点
- 用户已明确授权本次标准发布全链路；版本按 patch 递增，无需再次确认。
